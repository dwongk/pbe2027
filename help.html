Help

Welcome to the StudyTools website. This guide provides an overview of the available features and how to use them.

Navigation

  • Home – Browse the full list of books and categories.
  • Expanded / Condensed – Use the View buttons on the home page to switch between the full and AI-condensed views.
  • Search – Use your browser's find function (Ctrl+F / Cmd+F) to locate specific words or verses on any page.

Browsing a Book

On the home page, click any book name to expand it. Then click a category link (e.g. people, places, animals) to see all matching words and verses from that book.

Category Pages

Each category page shows a list of words found in the selected book, followed by the Bible verses that contain them.
